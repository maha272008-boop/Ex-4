# Exp - 4 HOSPITAL MANAGEMENT SYSTEM

# AIM:
To develop the Hospital management System using Star UML tool.

# SRS (Procedure):
STEP 1:

Hospital Management System is required to replace manual processes of managing patient records, doctor details, appointments, and billing.

STEP 2:

Manual processes cause difficulties in maintaining patient records, scheduling appointments, managing doctors, and handling payments.

STEP 3:

Patients face challenges in booking appointments, consulting doctors, accessing medical records, and checking prescriptions.

STEP 4:

Hospital administrators need an automated system to manage patients, doctors, appointments, rooms, medical records, and billing.

STEP 5:

The system should support patient registration, appointment booking, doctor scheduling, prescription management, online payments, and report generation.

STEP 6:

It must provide secure access for patients, doctors, administrators, and staff while protecting patient information and ensuring data security.
